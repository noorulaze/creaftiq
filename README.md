# Craftiq — Crafting Intelligent Digital Experiences

Craftiq is a modern, high-performance multi-page web application featuring bespoke spatial graphics, fluid animations, liquid glassmorphic UI components, and 7 branched page views.

## 🚀 Live Features & Page Branches

- **Home (`#home`)**: Impactful studio overview, founding metrics, core capabilities teaser, and featured showcase spotlight.
- **Services (`#services`)**: Filterable service suite spanning Web Ecosystems, Mobile Products, AI Systems, Media Production, Brand Engineering, and Enterprise Infrastructure.
- **Projects (`#projects`)**: Comprehensive portfolio showcase displaying live platforms (*DI Coin Platform, Personal Portfolios, MIC Learning Resource Centre, Irshad Volleyball League IVL Auction, Thenishal 2K25, Campus Chat & Vibe, Joao Felix Profile Showcase*).
- **About & Team (`#team`)**: Full profiles and direct contacts for the founding team (*Noorul Aze, Kasim Rahees, Aboobacker, Alfas, Abdul Wahid, Rabeeue*) and academic roots spotlight at *Darul Huda Islamic University*.
- **Estimator (`#estimator`)**: Interactive AI project cost and production timeline calculator.
- **Careers (`#careers`)**: Role definitions, benefits, and direct job application submission.
- **Contact (`#contact`)**: Direct studio directives, WhatsApp, phone, and FormSubmit email integration (`noorulazetirur@gmail.com`).

## 🛠️ Built With

- **HTML5 & CSS3** with Tailwind CSS & Custom Liquid Glassmorphism
- **React 18** & Babel Standalone
- **Lucide Icons**
- **FormSubmit API** integration
